VSTM Tune kuruldu

DAW'ını yeniden başlat ve eklenti taraması yap:

  • FL Studio: Options → Manage plugins → Find installed plugins
  • REAPER: Settings → Plug-ins → VST → Re-scan
  • Ableton Live: Settings → Plug-Ins → "Use VST3 Plug-In System Folders" açık → Rescan
  • Logic Pro / GarageBand: yeniden açınca AU listesi yenilenir

Daha önce dosyaları elle ~/Library/Audio/Plug-Ins/… altına kopyaladıysan, DAW iki kopya görmesin diye oradakileri sil.

Kaldırmak için Terminal'de:

sudo rm -rf "/Library/Audio/Plug-Ins/VST3/VSTM Tune.vst3" "/Library/Audio/Plug-Ins/Components/VSTM Tune.component" "/Applications/VSTM Tune.app"
