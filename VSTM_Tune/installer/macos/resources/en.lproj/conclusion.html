VSTM Tune is installed

Restart your DAW and rescan plug-ins:

  • FL Studio: Options → Manage plugins → Find installed plugins
  • REAPER: Settings → Plug-ins → VST → Re-scan
  • Ableton Live: Settings → Plug-Ins → "Use VST3 Plug-In System Folders" on → Rescan
  • Logic Pro / GarageBand: the AU list refreshes when you reopen them

If you copied the files by hand into ~/Library/Audio/Plug-Ins/… before, delete those copies so the DAW does not see two.

To uninstall, in Terminal:

sudo rm -rf "/Library/Audio/Plug-Ins/VST3/VSTM Tune.vst3" "/Library/Audio/Plug-Ins/Components/VSTM Tune.component" "/Applications/VSTM Tune.app"
